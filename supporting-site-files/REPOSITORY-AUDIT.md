# Public repository audit and improvement record

Reviewed 19 October 2026. Scope: 14 existing public repositories and the supplied college ZIP. The review combined repository inventories, README and notebook review, selected application/source inspection, credential-pattern scans and focused execution tests. It is not a complete security certification or an audit of every line of third-party code.

## New repositories

- **projects:** static visual website, six case studies, central README, source links, image provenance, reproducible chart script and supporting records.
- **benjanning:** clean professional profile README linking to the portfolio and selected projects.
- **cork-city-hotel:** sanitized original college booking-flow source, safe synthetic local mode, EJS screens, date/quantity/pricing tests and setup documentation. Original ZIP remains the preservation source.

## ZIP review and publication choices

The ZIP inventory contained 8,225 entries, including bundled dependencies, duplicate project copies, personal documents and configuration material. Only selected coursework source was extracted into the working area. Personal documents, private API exports, original database dumps, bundled dependencies, service keys and hotel photography with unclear redistribution rights were excluded from new public material.

The hotel application was selected because it has an understandable multi-step workflow and complete Express/EJS source. DB_App and miscellaneous HTML/database exercises were not chosen: they provide less complete, less distinctive portfolio evidence than the selected projects. The duplicated sorting folders and car deployment copy were treated as historical variants, not additional featured projects.

No external screenshots were fabricated. The new charts are computed from included educational data and separately labelled from original outputs. Academic prototypes are never described as production systems.

## Preservation

Existing Git histories, source references and licences were retained. Existing repositories were not deleted, renamed, made public/private or force-pushed. Repository updates use review branches and pull requests; generated-file removals remain recoverable in Git history. Only newly requested repositories were created as public.

## What remains limited

MySQL was not available for integration testing, so both applications were demonstrated using clearly labelled synthetic records. Existing deployment endpoints and weather integrations were not invoked. Notebook runs verify execution, not methodological or clinical validity. The historical benchmark CSV needs further aggregation review. Old coursework dependencies and teaching endpoints outside the selected projects remain historical and may require further work before reuse.
